# Tracker Eventos

Sistema de gestión de eventos, tareas y carga de trabajo desarrollado con Streamlit y SQLite.

## Funcionalidades

- Gestión de eventos
- Asignación de tareas
- Control de carga de trabajo
- Dashboard ejecutivo
- Gestión de gastos
- Historial
- Roles y login

## Tecnologías

- Python
- Streamlit
- SQLite
- Pandas
